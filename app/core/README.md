# Core Module (`app/core/`)

Provides application-wide core configurations and AI integrations.

## Components

- **`deepseek_config.py`**: Initializes the DeepSeek V3 API client via OpenRouter and configures Pydantic structured output validation schemas for automated listing appraisals.
