# Jupyter Notebooks (`notebooks/`)

Interactive Jupyter notebooks for data exploration, testing ETL transformations, and prototyping models across Medallion architecture layers.

## Subdirectories

- **`bronze/`**: Discovery and page extraction experiment notebooks (`discover.ipynb`, `extraction.ipynb`).
- **`silver/`**: Data cleaning and feature engineering notebook (`cleaning.ipynb`).
- **`gold/`**: Product dimension and fact evaluation notebooks (`dim_products.ipynb`, `ft_market_baselines.ipynb`, `ft_market_trends.ipynb`, `ft_price_changes_alert.ipynb`, `ft_arbitrage_opportunities.ipynb`).
